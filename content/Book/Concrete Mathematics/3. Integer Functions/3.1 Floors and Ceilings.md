
$$\lfloor x \rfloor = x \iff x \text{ is an integer} \iff \lceil x \rceil = x$$

$$\lfloor -x \rfloor = -\lceil x \rceil; \lceil -x \rceil = -\lfloor x \rfloor$$
The diference between x and ⌊x⌋ is called the **fractional part** of x, and
it arises often enough in applications to deserve its own notation:
$$\{x\} = x - \lfloor x \rfloor$$
