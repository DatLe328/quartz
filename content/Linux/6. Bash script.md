# Variable
```bash
a=10
b=20
echo "$a is smaller than $b"
```
# Argument
Example we have `test.sh` file
```bash
echo '$1 is my input, $2 is also my input'
```
Then we run this file:
```bash
./test.sh testinput1 testinput2
```
It will print `testinput is my input, testinput2 is also my input`
# For loop
```bash
for i in 1,2,3 do
	echo $i
done
```

```bash
for i in $(seq 1 50) do
	echo $i
done
```
# If else
**Remember space in the square bracket**
```bash
if [ "$1" == '' ] then
	echo 'You need to specify argument'
else
	echo 'Do something'
fi
```
