### 1. **Phép Toán Cơ Bản**

| Phép toán     | Cú pháp                                  | Hiển thị                        |
| ------------- | ---------------------------------------- | ------------------------------- |
| Cộng          | `a + b`                                  | $a+b$                           |
| Trừ           | `a - b`                                  | $a−b$                           |
| Nhân          | `a \times b` hoặc `a \cdot b` hoặc `a b` | $a \times b$, $a \cdot b$, $ab$ |
| Chia          | `a \div b` hoặc `\frac{a}{b}`            | $a \div b$, $\frac{a}{b}$       |
| Lũy thừa      | `a^b`                                    | $a^b$                           |

### 2. **Quan Hệ So Sánh**

| Phép toán         | Cú pháp    | Hiển thị   |
| ----------------- | ---------- | ---------- |
| Nhỏ hơn           | `a < b`    | $a<b$      |
| Lớn hơn           | `a > b`    | $a>b$      |
| Nhỏ hơn hoặc bằng | `a \leq b` | $a \leq b$ |
| Lớn hơn hoặc bằng | `a \geq b` | $a\geq b$  |
| Bằng              | `a = b`    | $a=b$      |
| Không bằng        | `a \neq b` | $a \neq b$ |
