| Tầng | Tên tầng         | Vai trò chính                                                      |
| ---- | ---------------- | ------------------------------------------------------------------ |
| 7️⃣  | **Application**  | Giao diện giữa người dùng và mạng (trình duyệt web, email...)      |
| 6️⃣  | **Presentation** | Mã hóa/giải mã, nén/giải nén dữ liệu (ví dụ: SSL, định dạng UTF-8) |
| 5️⃣  | **Session**      | Quản lý phiên làm việc giữa hai máy (mở, duy trì, đóng session)    |
| 4️⃣  | **Transport**    | Đảm bảo truyền dữ liệu đúng và đầy đủ (TCP, UDP)                   |
| 3️⃣  | **Network**      | Định tuyến, định địa chỉ (IP, ICMP, router)                        |
| 2️⃣  | **Data Link**    | Truyền dữ liệu giữa 2 thiết bị trong cùng mạng (MAC, switch)       |
| 1️⃣  | **Physical**     | Truyền tín hiệu vật lý qua cáp, sóng (Ethernet, Wi-Fi, điện...)    |

| Tầng OSI     | Ví dụ giao thức                                     |
| ------------ | --------------------------------------------------- |
| Application  | HTTP, SMTP, SNTP, FTP, SSH, DNS, DHCP, Telnet, IMAP |
| Presentation | SSL/TLS, JPEG, MP3                                  |
| Session      | NetBIOS, RPC                                        |
| Transport    | TCP, UDP                                            |
| Network      | IP, ICMP, ARP                                       |
| Data Link    | Ethernet, PPP, MAC                                  |
| Physical     | Cáp đồng, sợi quang, Wi-Fi                          |
