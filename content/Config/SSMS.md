- Download and install localdb  

| Command                             | Description                                      |
| ----------------------------------- | ------------------------------------------------ |
| `sqllocaldb info`                   | List all local database servers                  |
| `sqllocaldb info <instance_name>`   | Print the information about a LocalDB instance   |
| `sqllocaldb stop <instance_name>`   | Stop the LocalDB instance                        |
| `sqllocaldb start <instance_name>`  | Start the LocalDB instance                       |
| `sqllocaldb delete <instance_name>` | Delete the LocalDB instance (Stop before delete) |
