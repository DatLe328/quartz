# Big Integer
Should use Java for the `BigInteger` library

| Operation | Syntax          | Example                            |
| --------- | --------------- | ---------------------------------- |
| Plus      | `a.add(b)`      |                                    |
| Subtract  | `a.subtract(b)` |                                    |
| Multiply  | `a.multiply(b)` |                                    |
| Divide    | `a.divide(b)`   |                                    |
| Chech bit | `a.testBit(b)`  | `a = 10101, b = 0, a.testBit(b)=1` |
|           |                 |                                    |
Reference:
[K-Digit](https://oj.vnoi.info/problem/digit)
